Q1

科技头条每日抓取与 Excel 归档

练习模式 · 不限次数 · 提交后由大模型自动评分，达到 70 分即算通过

题目交付物提交答卷

一、题目背景

资讯运营同学每天需要人工打开「网易科技」和「新浪科技」两个站点，把首页头条的标题和链接复制到 Excel 里做选题记录。人工操作每天耗时 10 分钟以上，且经常漏记、错记、链接复制不完整。

现在需要把这个动作自动化：写一个程序，每天定时从下面两个站点各抓取 3 条头条信息，把标题和链接写入 Excel。

  • 网易科技：https://tech.163.com/
  • 新浪科技：https://tech.sina.com.cn/

二、任务描述

编写一个可每天自动运行的程序，实现：

  1. 从上述两个站点首页抓取各 3 条头条；
  2. 把每条头条的标题和链接写入 Excel；
  3. 支持每天自动执行，结果跨天累积、同一份 Excel 长期可查；
  4. 运行过程可重复、可追溯、失败可排查。

一句话评分口径：评委当场执行你提交的命令，程序抓到的 6 条头条必须和评委当场打开的浏览器首页头条一致，且 Excel 结构、链接可用、连续运行不产生重复数据。

三、功能需求（必须实现）

编号需求说明与验收要点
FR-1抓取两个站点分别请求 https://tech.163.com/ 与 https://tech.sina.com.cn/ 首页，不允许只做其中一个
FR-2每站提取 3 条头条取该站首页头条/要闻区域的前 3 条，顺序与页面展示顺序一致；标题与链接必须一一对应，不能错位、不能张冠李戴
FR-3写入 Excel输出 .xlsx 文件，字段见《附录 A》，每次运行写入 6 行数据（2 站 × 3 条）
FR-4链接可用链接必须写入完整可点击地址：以 http(s):// 开头，能在浏览器直接打开；Excel 中该单元格应为超链接
FR-5每天自动运行提供至少一种可落地的定时方案：系统定时任务（crontab / launchd / Windows 任务计划）或程序内置调度；必须给出可复制的安装命令
FR-6同一天重复运行幂等同一天内多次运行，Excel 中当天数据应被刷新而不是重复追加（不允许出现重复行）
FR-7跨天累积第二天运行后，前一天的数据仍保留，新数据按日期追加到同一份 Excel
FR-8失败处理与日志任一站点抓取失败时：程序不能崩溃，另一站点仍应正常写入；失败原因要落到日志或结果表中；两个站点全部失败时不得产生空数据文件
FR-9命令行可用至少支持「抓取一次」的标准入口；提供 --help；建议提供 --dry-run（只打印不写文件）等实用参数

四、技术要求与约束

编号约束
TR-1运行环境：普通笔记本或无图形界面的 Linux 服务器均可运行；不得依赖手动点击、不得要求人工复制粘贴
TR-2禁止使用浏览器自动化方案（Selenium、Playwright、Puppeteer 等）与浏览器插件/录制工具；必须通过 HTTP 请求 + HTML 解析实现
TR-3不得依赖需要登录、付费或申请密钥的接口/服务；只允许访问公开页面
TR-4允许使用第三方库，但必须提供依赖清单（requirements.txt 或等价的安装说明），且能在干净环境一次性装好
TR-5必须处理网络基本问题：超时、失败重试（≥ 2 次）、页面 gzip/压缩响应、字符编码（中文不得乱码）
TR-6单次运行总耗时建议 ≤ 60 秒；不得使用固定长 sleep 绕开问题
TR-7禁止硬编码：标题、链接不得写死在代码里，必须来自真实抓取；不同时间运行应能反映页面当期内容
TR-8代码要求：结构清晰、关键逻辑有注释、异常有处理；不要把所有逻辑堆在一个函数里
