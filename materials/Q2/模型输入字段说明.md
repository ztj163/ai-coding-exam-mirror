# 随题模型说明与输入字段口径（考生必读）

本题**不需要训练模型、不需要构造特征、不需要做类别编码**。随题提供一个训练好的 LightGBM 模型，你要做的是：

1. 按官方文档装好 LightGBM；
2. 把数据处理成模型需要的 **9 个数值列**（做 4 条简单清洗）；
3. `predict` 打分 → 按产能阈值分层 → 输出 Excel → 做意向分析。

## 一、先看官方文档（安装与调用）

- 安装与使用：**<https://lightgbm.cn/en/stable/Python-Intro.html#install>**
  - 安装：`pip install lightgbm`
  - 加载模型：`bst = lgb.Booster(model_file='lgbm_intent_model.txt')`
  - 预测：`ypred = bst.predict(data)`
- 参数与 API 参考：<https://lightgbm.cn/en/stable/Python-API.html>

> 本题只用到官方文档「安装 / 数据接口 / 预测」三节的内容，不需要训练、不需要调参。

### 模型概览

- 目标：`高意向_未来30天`（二分类）；快照日 2026-09-30；标签窗口 2026-10-01 ~ 2026-10-30；
- 输入：**9 个原始数值列**（见第四节），无任何派生特征与 One-Hot；
- 训练：79 轮，`learning_rate=0.05`、`num_leaves=31`；5 折 CV **AUC 0.8662**；
- 在 `历史数据_效果验证用` 上：AUC **0.8463**、PR-AUC 0.5488、KS 0.5412、召回率@Top20% **0.65**、提升度 3.25。

> 你在验证集上算出的指标应接近上面的数字；若 AUC 掉到 0.6 左右，几乎一定是**输入列顺序不对**。

## 三、数据清洗规则（4 条）

快照日固定 **2026-09-30**。

| # | 规则 | 说明 |
| --- | --- | --- |
| 1 | **日期解析** | `首次接触日期`、`最近互动日期` 里有 `2026/3/5` 这类文本，需统一解析为日期 |
| 2 | **重算 `最近互动距今天数`** | 一律用 `2026-09-30 − 最近互动日期` 重算（原列存在未同步的脏值 `-1`）；负数记为缺失 |
| 3 | **异常值置缺失** | 员工数为 0 或 99999、年营收 ≤ 0 或极大、计数类字段出现 999 等占位符 —— 都不是真实业务值，置为缺失（`NaN`） |
| 4 | **渠道写法归一** | 19 种写法归为 6 个标准渠道（映射表见下）。**归一后的渠道不进入模型**，只用于后面的分组分析 |

**缺失值不需要填充**：LightGBM 原生支持缺失值，直接保留 `NaN` 即可（不要填 0、不要删行）。

## 四、模型输入：9 个原始数值列（顺序固定）

| # | 列名 | 说明 |
| --- | --- | --- |
| 1 | 最近互动距今天数 | 按规则 2 重算 |
| 2 | 近30天互动次数 | 清洗后的原始值 |
| 3 | 近30天网站访问次数 | 清洗后的原始值 |
| 4 | 近30天资料下载次数 | 清洗后的原始值 |
| 5 | 近30天活动参与次数 | 清洗后的原始值 |
| 6 | 近30天邮件打开率 | 清洗后的原始值（0~1） |
| 7 | 报价次数 | 清洗后的原始值 |
| 8 | 员工数 | 清洗后的原始值 |
| 9 | 年营收_万元 | 清洗后的原始值 |

> 只有这 9 列能传给模型。`客户ID`、`客户名称`、`联系电话`、`所属行业`、`公司规模`、`所在地区`、`客户来源渠道`、`当前销售阶段`、`是否决策人对接`、`客户经理`、`数据来源系统` **都不是模型输入**——它们用于分组分析与结果展示。
>
> 把非数值列传进模型会直接报错（例如 `could not convert string to float: 'KH003583'`），这其实是好事：错误会立刻暴露。真正危险的是**9 列顺序错乱**（模型按位置读取特征），实测 AUC 会从 0.88 掉到 0.61。

## 六、常见坑

1. **9 列顺序错乱**：模型按位置读特征，务必用 `df[FEATURES]` 强制顺序；
2. **忘了重算 `最近互动距今天数`**：原列的 `-1` 会被模型当成"刚刚互动过"，实测 AUC 掉约 0.01；
3. **把缺失填成 0**：模型原生支持缺失，填 0 会引入错误信号；
4. **把 `所属行业` 等文本列也传给模型**：会直接报类型错误；
5. **对待预测集去重/删缺失**：会导致输出不满 800 行，直接失分；
6. **重新训练模型**：本题要求使用随题模型，重新训练属于不按要求作答。
